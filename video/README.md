# ویدیوهای آموزشی سامانه رستوران

شش ویدیو، هر کدام با متن گویندگی جدا:

| فایل متن | ویدیو | مدت تقریبی |
|---|---|---|
| `narration/roadmap.txt` | نقشه راه: مسیر یک سفارش (ساده) | ۳ دقیقه |
| `narration/waiter.txt` | راهنمای کامل گارسون | ۵ دقیقه |
| `narration/kitchen.txt` | راهنمای کامل آشپزخانه | ۳ دقیقه |
| `narration/bar.txt` | راهنمای کامل بار | ۲ دقیقه |
| `narration/cashier.txt` | راهنمای کامل صندوقدار | ۴ دقیقه |
| `narration/manager.txt` | راهنمای کامل مدیر | ۴ دقیقه |

## صدا — بدون نیاز به همگام‌سازی

هر بند متن با شماره شروع می‌شود: `[01]`، `[02]`، … برای **هر بند یک فایل صوتی جدا** بسازید و
شماره‌اش را اسم فایل بگذارید (خود شماره‌ی داخل کروشه را نخوانید):

```
audio/waiter/01.mp3
audio/waiter/02.mp3
...
```

هر صحنه‌ی ویدیو خودش را با طول همان فایل تنظیم می‌کند، پس سرعت گوینده مهم نیست و چیزی جابه‌جا نمی‌شود.
فرمت‌های mp3، wav، m4a، aac، ogg، flac و opus قبول است.

اگر ابزار تبدیل متن به صدای شما فقط یک فایل کامل می‌دهد، آن را `audio/<نام>/full.mp3` بگذارید؛
فایل در مکث‌های بین بندها بریده می‌شود (کافی است بین بندها کمی مکث باشد). روش فایل جدا مطمئن‌تر است.

## ساخت

```bash
npm install                 # یک بار
node capture.mjs waiter     # ضبط صفحه‌ها (سرور و دیتابیس جدا، به دیتابیس اصلی دست نمی‌زند)
node assemble.mjs waiter    # ساخت out/waiter/waiter.mp4 — بدون صدا: out/waiter/waiter-draft.mp4
```

`node sheet.mjs waiter check.png 0.5` از وسط هر صحنه یک تصویر برای بازبینی می‌سازد.

اگر ظاهر برنامه عوض شد، فقط `capture` را دوباره اجرا کنید؛ صداها دوباره لازم نیست، مگر این‌که متن عوض شده باشد.
